# Qiming Manufacturing operating analysis

Qiming Manufacturing is a fictional company. Every operating figure, customer, peer comparison, management discussion, media observation, and research note in this directory is simulated for FinFlow product demonstrations.

The case demonstrates:

- PostgreSQL extraction;
- a local market and macro data API;
- deterministic joins and KPI calculations;
- PDF, Word, Markdown, text, and CSV knowledge inputs;
- AI-assisted operating analysis;
- interactive financial reporting and management presentation output.

The materials are not investment advice and must not be represented as information about a real company.
