# 多源经营数据加工样板

这个案例演示业务人员如何把多种来源的明细数据和维表编排成可重复运行的加工工作流。

## 数据源

- CSV：20,000 行模拟经营订单明细。
- Excel：1,000 行门店维表，工作表名为“门店维表”。
- HTTP API：CNY、USD 和 EUR 模拟汇率，由案例 API 以 NDJSON 返回。
- PostgreSQL：10 个区域的月度经营目标。

## 加工逻辑

1. 选取分析字段并排除取消订单。
2. 以 `store_code` 按 M:1 关联门店维表。
3. 以 `currency` 按 M:1 关联 API 汇率。
4. 计算折算人民币金额，再按区域汇总。
5. 关联数据库经营目标，计算达成差额。
6. 验证维表键唯一、关联匹配率与结果行数，最终输出 Parquet。

`assets/百万行宽表验证记录.json` 保留了同一编排在 100 万行、300 列明细及
1,000 行、300 列维表上的实测结果。可使用仓库根目录的
`scripts/benchmark-data-transform.py` 重复生成大数据并验证。
