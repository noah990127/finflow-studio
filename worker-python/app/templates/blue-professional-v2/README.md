# Blue Professional v2

Source: https://github.com/zarazhangrui/beautiful-html-templates/tree/main/templates/blue-professional
License: MIT, see blue-LICENSE. Original HTML is bundled unchanged.

The adapter hydrates the upstream timeline/detail DOM and preserves upstream CSS.
offline.css supplies local CJK fonts, a fixed export canvas and a relationship table extension.
No Google fonts, network assets, example copy or upstream navigation scripts are executed.
Export: html-to-pptx 0.2.1 (MIT), Chromium measurement and native editable PowerPoint objects.
This is not Presenton and does not promise exact cross-application typography.

Deploy html-to-pptx and its dependencies from the approved internal wheel mirror,
Playwright Chromium, Noto Sans CJK SC, LibreOffice and Poppler in the offline image.
Never silently replace this renderer with the legacy text renderer.
