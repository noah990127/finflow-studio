# Frontend UX Principles

- Keep the platform visually quiet, minimal, and easy to scan. Avoid accumulating permanent information and toolbars.
- Place secondary actions beside existing headings or in contextual menus; do not add a full-width row for a few buttons.
- Use familiar icons with accessible names and hover tooltips for compact tools. Keep primary actions clear.
- Reveal technical details and advanced controls on demand. Preserve comfortable whitespace rather than squeezing more information into the viewport.
- Check long titles, narrow layouts, and expanded states so controls stay reachable without overlapping content.
